## Fora desta feature (explicitamente)

- Instalador ou pacote para Linux e macOS; assinatura de código; atualização automática; iniciar com o sistema (backlog); MSIX e instalação para todos os usuários.
- Trocar `file://` por um protocolo próprio para desligar a Fuse `GrantFileProtocolExtraPrivileges` (alternativa registrada no ADR-0018).
- Funcionalidade nova no app.

## Notas

- **Etapa anterior (2026-11-18):** a Etapa 6 (feature 06) e a conversa (feature 07) esperam a verificação no Windows. A dona do projeto autorizou escrever estas tarefas assim mesmo; a ideia é fazer as três verificações do Windows na mesma sessão, com o instalador.
- O instalador NSIS só é gerado no Windows (ADR-0018); no Linux, o `pack:check` monta o app sem instalador e confere o que dá.

### Verificações executadas

- **T8.01 (Linux, Node 22.23.2, 2026-11-18):** `npm run check` com 60 arquivos e 459 testes aprovados (novo: `tests/build/package-manifest.test.ts`, versão 1.0.0, nome "Fai", descrição "ilustrada", `dependencies` vazio e as quatro bibliotecas do app em `devDependencies`). `npm run build` com saída 0: `out/main/index.js` (1,3 MB) só faz `require` de `electron` e de `node:*` (o SDK traz `node:child_process` e `node:readline` internos, não usados com a chave explícita). `npm run preview` (dados copiados e restaurados) abriu as três janelas sem erro no log. Mutações (2, mortas): `zod` de volta em `dependencies`, versão antiga.

- **T8.02 (Linux, Node 22.23.2, 2026-11-18):** `electron-builder` **26.18.1** instalado como dependência de desenvolvimento, versão exata, aprovado pela dona do projeto. `npm run check` com 61 arquivos e 466 testes aprovados (novo: `tests/build/installer-config.test.ts`, `appId` igual ao `APP_USER_MODEL_ID` do app, nome "Fai", `Fai-Setup-${version}.${ext}`, NSIS por usuário sem elevação e sem escolher pasta, atalhos "Fai", abrir ao terminar, dados mantidos, pt-BR, NSIS x64 com o ícone da estrela, só `out/**` e os três ícones, Fuses iguais a `tools/package/fuses.json` e à lista do ADR-0018, `dist:win` e nenhum script com comandos de um shell só).
