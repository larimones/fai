# Revisão de segurança do app empacotado — Feature 08

Conferida contra a linha de base do ADR-0007, o ADR-0017 (rede só no main) e o ADR-0018 (empacotamento). Cada item diz como foi conferido e onde; o que só o Windows confirma fica marcado para a verificação final.

- **Máquina:** Linux (Ubuntu 24.04.5, Node 22.23.2), 2026-11-18, depois da T8.04 (`0d8fc4a`).
- **Pacote conferido:** `dist/linux-unpacked` montado pelo `npm run pack:check` com a mesma configuração do instalador do Windows.

## Riscos que continuam

- `GrantFileProtocolExtraPrivileges` ligada: uma página `file://` tem mais acesso a arquivos locais do que teria por um protocolo próprio. Mitigado pela CSP, pelo bloqueio de navegação e pelo `sandbox`; trocar por um protocolo próprio está registrado no ADR-0018 como alternativa futura.
- Sem assinatura, o Windows não garante a origem do `.exe`.
