### Verificações executadas (Linux, Ubuntu 24.04, sessão Wayland, Node 22.23.2)

- `npm run typecheck`: sem erros.
- `npm run lint`: sem erros. Arquivos de sonda temporários em `src/domain` e `src/renderer` importando `electron`/`node:fs`/`../shared` geraram os 5 erros esperados de `no-restricted-imports` e foram removidos.
- `npm test`: 7 arquivos e 19 testes aprovados (domínio, arquitetura, componente `App`, preload, _handler_ IPC, _sender guard_/URL do app, `secureWebPreferences`).
- `npm run build`: `out/main/index.js`, `out/preload/main.js` (CommonJS), `out/renderer/` com a CSP de produção no `<meta>`.
- `npm run dev`, inspecionado via CDP: UI mostra "Fai v0.1.0 · Linux" (obtido por IPC); `typeof require` e `typeof process` são `"undefined"`; `window.fai` tem só `app.getInfo`; `window.open` retorna `null`; `fetch` remoto é bloqueado pela CSP; sem aviso "Insecure Content-Security-Policy".
- Build de produção (`electron .`, `file://`): os mesmos resultados com a CSP estrita; CSS carregado; `window.close()` encerrou o Electron com código 0.
- O sandbox do Chromium iniciou normalmente apesar de `kernel.apparmor_restrict_unprivileged_userns = 1`.
